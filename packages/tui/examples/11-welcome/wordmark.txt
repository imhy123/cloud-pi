# Cloud Pi 启动字标 —— 手绘草稿
#
# 直接画“半方块字符”，所见即所得（omp 的 omp 字标就是这么写死的）：
#
#     █   整格实心（上下两个像素都有）
#     ▀   只有上半格
#     ▄   只有下半格
#     ▔   分隔横线：开场参与渐变，动画结束后变灰
#     空格 空
#
# 规则：
#   - 每行就是终端里的一行；行数不限（2 行 = 4 像素高，3 行 = 6 像素高）。
#   - 行宽不必手算，按最长行对齐即可；行尾空格可以省。
#   - 改完保存这个文件，然后告诉我“按 wordmark.txt 来”就行。
#
# 可选设置（去掉行首的 # 才生效）：
#   @color gradient      # gradient = 渐变 + 扫光动画（当前效果）；text = 纯主题文字色，omp 字标就是这种
#   @version v0.1.0
#   @tip Tip: Ctrl+C exits Cloud-Pi.
#
